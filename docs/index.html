Installation

Requires macOS, iTerm2, Node on PATH, and a Swift toolchain (plain swiftc — no Xcode).

1. Install the plugin

/plugin marketplace add ~/.claude/tricorder-src
/plugin install tricorder@tricorder

2. Wire the statusline (plugins can't contribute one — add this once to ~/.claude/settings.json)

"statusLine": {
  "type": "command",
  "command": "\"${CLAUDE_PLUGIN_ROOT}\"/bin/tricorder statusline"
}

3. Build and launch the menu-bar app

npm install
npm run build:bar
cp plugin/bar/TricorderBar.app ~/Applications/ -R
sed "s|__HOME__|$HOME|g" bar/com.gago.tricorder.bar.plist > ~/Library/LaunchAgents/com.gago.tricorder.bar.plist
launchctl load ~/Library/LaunchAgents/com.gago.tricorder.bar.plist

macOS will ask once to let Tricorder control iTerm2 (for session focus, restore, and the Enterprise flyby) — allow it.

Full details, configuration, and the CLI reference live in the repo README.
